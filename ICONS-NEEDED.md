# Icon Files Needed

This extension requires three PNG icon files:

- `icon16.png` (16x16 pixels)
- `icon48.png` (48x48 pixels)
- `icon128.png` (128x128 pixels)

## Quick Solution for Testing

Download these placeholder images and save them in the extension folder:

1. Go to: https://via.placeholder.com/16/2c3e50/FFFFFF?text=H4
   - Right-click → Save as `icon16.png`

2. Go to: https://via.placeholder.com/48/2c3e50/FFFFFF?text=H4
   - Right-click → Save as `icon48.png`

3. Go to: https://via.placeholder.com/128/2c3e50/FFFFFF?text=H4
   - Right-click → Save as `icon128.png`

## Custom Icon Design

For a professional icon, create a square design that represents:
- Hotel booking
- Restaurant cross-reference
- Administrative tools

Recommended colors matching Hotel Number Four branding or use:
- Primary: #2c3e50 (dark blue-grey)
- Accent: #4a90e2 (blue)

Export at all three sizes and replace the placeholder files.
